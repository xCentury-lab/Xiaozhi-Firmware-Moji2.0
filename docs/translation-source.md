## 1. 翻訳対象ファイルの特定方法

Phase 0-A で本家 `78/xiaozhi-esp32` の以下を確認:

```powershell
cd C:\xiaozhi-work\xiaozhi-esp32

# 文字列ファイルの形式特定
Get-ChildItem -Path main/assets -Recurse -File | Select-Object FullName, Length

# UI 文字列を含むソースを grep
Select-String -Path main/*.cc -Pattern "i18n|gettext|tr\(|_\(" -SimpleMatch
```

## 4. 翻訳ワークフロー

1. **下訳**: DeepL API で一括機械翻訳
2. **文脈補正**: 翻訳者が UI 実画面を見ながら調整
3. **用語統一**: `glossary-ja.md` に照合
4. **社内レビュー**: 営業・サポート2名がクロスチェック
5. **実機検証**: Phase 2-C（日本語UI調整）で再調整

## 5. 外部翻訳会社活用時の注意

- NDA 締結必須（OEM情報が含まれる可能性）
- 対象ファイル形式（`.po` / `.json`）に対応できる業者選定
- 納期は STEP2 開始から **5営業日以内** を目安
